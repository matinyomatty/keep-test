# Keep

Point of sale for shops in Tanzania. Served at **keep.co.tz** by GitHub Pages.

| Folder | What it is |
|---|---|
| `/` | Sign-in page. Sends each person to the right place after they sign in. |
| `/hq/` | Keep HQ (vendor portal) |
| `/app/` | Shop till (minimarket, hardware, electronics…) |
| `/barber/` | Barbershop app (pilot, data on device for now) |

Firebase project: `matinyopos`. Security rules are kept out of this repository on purpose.
